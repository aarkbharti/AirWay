# AirAware - Air Quality Dashboard

AirAware is a React-based web application that provides real-time air quality information and a 24-hour timeline for cities worldwide. It uses the OpenWeather API to retrieve accurate metrics like AQI, PM2.5, PM10, Carbon Monoxide, and more.

## Features

- **Real-Time Data:** Check the immediate Air Quality Index (AQI) of any city.
- **Pollutant Breakdown:** Detailed readings for PM2.5, PM10, O3, CO, NO2, and SO2.
- **24-Hour Timeline:** Interactive line chart mapping the air quality over a 24-hour period.
- **City Search:** Built-in geocoding to quickly search and select locations globally.
- **Responsive Design:** Fully mobile-friendly UI.
- **Dark/Light Mode:** Toggleable themes that adapt to your reading preference.

## Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **API Requests:** Axios
- **Data Source:** OpenWeather API (Air Pollution & Geocoding APIs)
